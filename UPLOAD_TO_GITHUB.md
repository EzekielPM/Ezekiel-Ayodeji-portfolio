# Uploading this portfolio to GitHub

## Important

Do not upload the ZIP file as one file. Extract it first, then upload the files and folders inside the extracted portfolio folder.

The repository root must show `app`, `public`, `package.json` and the other project files directly. They must not be hidden inside another folder.

## If the repository is empty

GitHub may not show an **Add file** button yet. On the Quick setup page, find the sentence that contains **uploading an existing file** and select that link.

You can also add `/upload/main` to the end of your repository address. For example:

`https://github.com/YOUR-USERNAME/olusola-ayodeji-portfolio/upload/main`

## If the repository already contains a file

Open the repository, select **Add file** above the file list, then select **Upload files**.

## Upload steps

1. Extract the downloaded ZIP file.
2. Open the extracted portfolio folder.
3. Select all the files and folders inside it.
4. Drag them onto GitHub's upload page.
5. Enter `Initial portfolio upload` as the commit message.
6. Select **Commit changes**.

If you are using a phone, open GitHub in Chrome and enable **Desktop site**. A laptop is recommended because the portfolio contains many images and documents.

## Deploy after uploading

1. Go to `https://vercel.com` and sign in with GitHub.
2. Select **Add New**, then **Project**.
3. Import `olusola-ayodeji-portfolio`.
4. Confirm that the framework is **Next.js**.
5. Select **Deploy**.
