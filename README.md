# Olusola Ayodeji Ezekiel Portfolio

Professional portfolio of Olusola Ayodeji Ezekiel, showcasing product management case studies, digital products, construction projects and project leadership experience.

## Portfolio contents

- Product case studies for Siiqo, Canvoy Payment and Wayagram
- Six documented construction projects
- Scrollable project galleries with image enlargement
- Product and construction CV downloads
- Supporting product documents
- LinkedIn, email, WhatsApp and telephone contact options

## Run locally

1. Install Node.js 20 or later.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Deploy with Vercel

1. Upload this project's files to a GitHub repository.
2. Sign in to Vercel with GitHub.
3. Select **Add New**, then **Project**.
4. Import the GitHub repository.
5. Keep the automatically detected Next.js settings.
6. Select **Deploy**.

Vercel will provide a public `.vercel.app` address. New commits to the GitHub repository will deploy automatically.
